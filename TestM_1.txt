## 一、数据、3D 可视化、交互状态的解耦方式

这个项目通过**分层架构**和**关注点分离**把三块内容清晰地解耦开了：

### 1. 数据层 — `src/data/mockData.ts`
- **纯数据，无依赖**：只负责提供设备列表数据 `factoryEquipment` 和数据生成函数 `updateEquipmentSensorData`
- **不依赖任何渲染库或状态管理**：不导入 Three.js 或 Vue 的响应式 API
- **格式标准化**：数据结构严格遵循 `src/types/index.ts` 定义的 `Equipment` 接口

### 2. 3D 可视化层 — `src/composables/` + `src/utils/equipmentFactory.ts`
- **渲染独立于业务数据**：
  - `useThreeScene.ts` 负责场景初始化、相机、灯光、网格添加等 3D 渲染核心逻辑
  - `equipmentFactory.ts` 采用**工厂模式**，根据设备类型 `EquipmentType` 创建对应的 Three.js `Object3D`
- **通过 mesh 引用桥接**：`Equipment` 接口中的 `mesh?: THREE.Object3D` 字段充当数据和 3D 对象之间的桥梁
- **分层的 composables**：
  - `useThreeCore.ts` — 场景/相机/渲染器核心
  - `useLights.ts` — 灯光管理
  - `useAnimationLoop.ts` — 动画循环
  - `useEquipmentState.ts` — 设备状态（虽然文件是空的，但从 `useThreeScene.ts` 的导入可以推断其职责）

### 3. 交互状态层 — `src/composables/useThreeScene.ts` + Vue Components
- **Vue 响应式驱动**：
  - `selectedEquipment`、`currentView`、`isAnimating` 等状态使用 Vue 的 `ref`
  - `alarmEquipment` 使用 `computed` 派生
- **事件驱动交互**：
  - `handleMouseClick` — 射线拾取（Raycaster）点击设备
  - `switchCameraView` — 视角切换
  - `toggleAnimation` — 动画控制
- **组件分层承担不同交互职责**：
  - `ControlPanel.vue` — 左侧控制面板（视角、状态统计、动画开关）
  - `EquipmentInfoPanel.vue` — 右侧设备详情面板
  - `FactoryVisualization.vue` — 主容器，通过 dat.GUI 提供调试级交互

### 解耦的关键设计模式：
- **工厂模式**：`equipmentFactory.createEquipment()` 根据类型创建不同 3D 对象
- **组合式函数（Composables）**：把 3D 渲染逻辑拆成多个可组合的 hook
- **类型契约**：`src/types/index.ts` 定义了各层之间的接口规范
